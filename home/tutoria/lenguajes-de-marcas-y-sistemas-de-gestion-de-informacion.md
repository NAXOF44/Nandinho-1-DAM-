## Lenguajes de Marcas

### UT1. Introducción a los lenguajes de marcas

Los **lenguajes de marcas** son sistemas que permiten estructurar y dar significado a la información por uso de etiquetas o marcas.

#### ¿Qué son?

Un lenguaje de marcas permite definir la **estructura y presentación de un documento**. Algunos de los más conocidos son **HTML** y **XML**.

### Características principales

* Permiten estructurar información.
* Utilizan marcas o etiquetas.
* Facilitan el intercambio de información.
* Pueden ser interpretados por diferentes aplicaciones.
* Son muy utilizados en el desarrollo web.

### Pasos básicos para crear un documento HTML

1. Crear el archivo con extensión `.html`.
2. Añadir la estructura  del html.
3. poner el contenido por etiquetas.
4. Guardar el archivo.
5. Abrirlo con un navegador web.

### Ejemplo de código HTML

```html
<!DOCTYPE html>
<html>
<head>
    <title>Mi primera página</title>
</head>
<body>
    <h1>Lenguajes de Marcas</h1>
    <p>Este es un documento HTML.</p>
</body>
</html>
```

### HTML vs XML

| Característica | HTML              | XML                                |
| -------------- | ----------------- | ---------------------------------- |
| Uso principal  | Crear páginas web | Almacenar e intercambiar datos     |
| Etiquetas      | Predefinidas      | Personalizables                    |
| Presentación   | Sí                | No está enfocada a la presentación |
| Estructura     | Flexible          | Más estricta                       |
| Ejemplo        | `<h1>Título</h1>` | `<nombre>Nandinho</nombre>`        |

### Web de referencia

> 💡 **Apunte importante:** HTML se utiliza principalmente para estructurar el contenido de las páginas web, mientras que XML está orientado principalmente a estructurar y transportar datos.

### Conclusión

Los lenguajes de marcas son fundamentales para organizar y representar información.&#x20;

**HTML** es uno de los principales lenguajes utilizados en la creación de páginas web, y el  **XML** permite estructurar datos de forma organizada y flexible.
